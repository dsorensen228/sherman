# Concept Assets

This directory holds product renders and deterministic design sheets used as intent references. Artistic renders are not mechanical drawings. Do not measure them or infer clearances, wheel geometry, camera field of view, or component placement from them.

Planned assets:

- `sherman-final-product-render.png`: three-quarter artistic product render.
- `sherman-desk-context.png`: scale and behavior context on a real desk.
- `sherman-goal-sheet.svg`: editable deterministic broad-goal visual generated from the documented requirements.
- `sherman-goal-sheet.png`: verified 1600 × 900 rendered version for easy preview/sharing.

Source prompts and generation notes live in `PROMPTS.md`.
