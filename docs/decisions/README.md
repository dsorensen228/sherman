# Architecture Decision Records

Create `NNNN-short-title.md` using the sections: Status, Context, Decision, Alternatives, Consequences, Verification, Rollback, and Links. Status is Proposed, Accepted, Superseded, or Rejected.

An ADR is required for language/runtime changes, safety authority, wire formats, storage engines, OS baselines, display/electrical architecture, exact motor/battery family, chassis envelope freeze, privacy defaults, and any decision that changes multiple owned areas.
