# Developer and Operations Tools

## Scope

`tools/` owns reproducible developer utilities for build/provision, hardware receiving/identity, calibration capture/solve, replay/trace inspection, scenario launch, protocol diagnostics, metrics/log analysis, evidence packaging, documentation/traceability checks and release manifests.

Tools must be safe by default. No utility may provide an undocumented path around arm/safety/privacy or upload/capture data implicitly.
